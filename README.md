# 📝 Gestor de Tareas (To-Do List)

Una aplicación web ligera y funcional desarrollada con JavaScript Vanilla para organizar las tareas del día a día de forma interactiva y sencilla.

---

## 🚀 Funcionalidades

* **Crear tareas:** Agrega nuevas actividades escribiéndolas en el campo de texto.
* **Control de estado:** Marca las tareas como completadas mediante un checkbox; esto aplicará un estilo de tachado automático.
* **Eliminar elementos:** Borra cualquier tarea de la lista de manera individual.
* **Contador en tiempo real:** Visualiza de forma dinámica el total de tareas, cuántas has completado y cuántas tienes pendientes.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura de la interfaz.
* **CSS3:** Estilos y diseño visual.
* **JavaScript (ES6+):** Manipulación del DOM, gestión de eventos y control de estado local mediante arrays.

---

## 💻 Instalación y Uso

1. Clona el repositorio o descarga los archivos del proyecto en tu computadora.
2. Asegúrate de tener la estructura básica de archivos (`index.html`, tu archivo de estilos y tu script de JavaScript).
3. Abre el archivo `index.html` directamente en tu navegador web favorito para empezar a usar la aplicación.
